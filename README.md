- Anti-Link
- Anti-Bad Words
- Group Management
- And much more!

## 📦 Setup
1. Install dependencies: `npm install`
2. Set your `SESSION_ID` in environment variables
3. Set your `OWNER_NUMBER` in environment variables if owner-number based features are needed
4. Run: `npm start`
